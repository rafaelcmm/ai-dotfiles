# Code Block Conversions

Before/after examples for fenced code blocks, including how to escape literal
triple-backtick sequences inside a markdown code block.

````text

    your code here
    ```

    ```html
    <pre><code class="language-md">
    your code here
    </code></pre>
    ```

    ```js
    console.log("Hello world");
    ```

    ```html
    <pre><code class="language-js">
    console.log("Hello world");
    </code></pre>
    ```
````
